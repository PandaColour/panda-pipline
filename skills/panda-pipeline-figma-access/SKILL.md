# Figma 访问

仅当前需求以 Figma 为设计来源，且本轮需要远程读取或核实降级原因时加载。调用方必须给出阶段、需求范围和角色权限；本 skill 不授权下载、修改物料、更新客户端配置或 Token。

执行前读取 [访问与冷却规范](references/access.md)。先核对已有来源与冷却记录，再发现工具、读取适用的 MCP 自带规范，按实际 schema 请求当前必要节点。MCP 服务自带的 skill 保留原名，不能以读取本文替代。

结果写入角色原有报告：调用方式、范围、实际结果、缓存来源、失败与冷却条件；不得将发现成功记成设计读取成功。远程不可用时继续利用本地依据高还原，仅记录对应缺口。回执补正、记忆整理、总结和仅复用有效证据的复审不额外联网；首审/复审边界与角色写入范围仍由 prompt 决定。
